Spec notes · All phases · (reference sheet) — not part of the UI

Every component the mockups use, with its class name, states and the rule that governs it. Port these first; screens are compositions of them.

Rules

  • Facts (immutable) use .fact / .addr / seals. Claims (mutable, signed) use .claim. Never style a claim like a fact or vice versa.
  • Store colours (.dot.a/.b/.c) identify stores only. Durability colours (.s-*) describe keeping only. They never share a hue.
  • Every byte figure uses NFB.bytes(). Every count uses thousands separators.
  • Status always pairs an icon with a word.
