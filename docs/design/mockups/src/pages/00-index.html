Mockups

Standalone HTML targets for implementation agents. Each file opens on its own (fonts from Google Fonts, falling back to system fonts). Match layout, hierarchy, copy and states. Below each screen, a dashed Spec notes panel holds behaviour and acceptance criteria; the same notes are in an HTML comment at the top of each file.

How to use these

  1. Start with Components and port src/kit.css tokens and classes, plus the Seal algorithm in src/kit.js (normative).
  2. Build the screens for your phase. Treat text and number formatting as part of the spec.
  3. Check light and dark (buttons bottom-right). Target width 1280–1600 px; the shell collapses the rail under 1100 px and the nav under 820 px.
  4. Elements outside .app (spec panel, theme buttons) are mockup chrome. Don't ship them.
  5. Edit mockups in src/pages/ and run python3 src/build.py.
